# BASIC Computer Games

This directory contains a locally imported collection of historical BASIC
listings associated with David H. Ahl's 1978 *BASIC Computer Games:
Microcomputer Edition*. Basicade registers only the programs that pass its WASM
startup smoke tests; see the catalog and test suite for the supported subset.

The original import did not retain its download URL, upstream revision, or a
file-by-file chain of custody. Basicade therefore cannot claim that these files
are byte-for-byte transcriptions from one identified scan or upstream archive.
The 1978 edition is retained as the collection-level bibliographic reference:

- [Internet Archive reference edition](https://archive.org/details/Basic_Computer_Games_Microcomputer_Edition_1978_Creative_Computing)
- [Licence and provenance status](LICENSE-STATUS.md)

Use Git history to review Basicade changes. Record an upstream URL, revision,
edition, and the nature of the change whenever a listing is replaced or
retranscribed.
