# Licence and provenance status

This collection contains historical BASIC listings associated with David H.
Ahl's 1978 *BASIC Computer Games: Microcomputer Edition*. The original import
did not retain a download URL, upstream revision, or file-by-file source record.
Basicade therefore does not claim authorship, assert a complete chain of
custody, or apply the repository's MIT licence to these listings.

## Public-domain basis

On June 15, 2022, David Ahl published a notice placing everything he had written
or edited into the public domain. A preserved transcription of that notice is
available in the [Coding Horror project discussion](https://discourse.codinghorror.com/t/updating-101-basic-computer-games-for-2022-and-beyond/7927/126).
An earlier, independent [2017 account from Jeffrey Henning](https://troypress.com/play-basic-computer-games-online/)
states that Ahl directly confirmed that he had placed these games in the public
domain after selling *Creative Computing*.

Basicade relies on those statements as the collection's public-domain basis.
Because the book compiled programs by multiple contributors and this import's
exact upstream source is unknown, this record is not a warranty that every
possible third-party interest or later modification has been independently
cleared.

## Identification and maintenance

The [Internet Archive copy of the 1978 edition](https://archive.org/details/Basic_Computer_Games_Microcomputer_Edition_1978_Creative_Computing)
is the bibliographic reference for the collection. It is not claimed as the
verified byte source of the local files. Git history records the files imported
into Basicade and all subsequent compatibility changes; it does not establish
the unknown file-level origin of the initial import.

Preserve original author credits in the listings. When replacing or
retranscribing a file, record its source URL, edition, upstream revision when
applicable, and the nature of the change. If the exact byte source of the
initial import is recovered later, record it in an immutable import manifest
that is not rewritten for local compatibility fixes.
